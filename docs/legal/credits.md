# Шрифты и сторонние компоненты

Интерфейс использует локально поставляемые Manrope и JetBrains Mono по SIL Open Font License 1.1. Inter Tight может присутствовать в зависимостях старых сборок и также распространяется по SIL OFL 1.1

Иконки Radix Icons распространяются по MIT. React, Vite, Yjs и другие библиотеки сохраняют свои лицензии; точные версии закреплены в pnpm-lock.yaml. Состав зависимостей не означает единой лицензии на весь Raven

Серебристый знак адаптирован для Raven из его прежней эмблемы. Вращающаяся эмблема представляет собой замкнутую объёмную геометрию, построенную из собственного знака Raven без сторонней модели. Иллюстрация рабочего пространства снята в самом приложении и содержит вымышленные сведения
